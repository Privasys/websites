The CLI is a single native binary for **Windows, macOS and Linux** (x86-64 and Arm64). On Windows it runs natively in PowerShell or Command Prompt: WSL is not needed.

<Tabs groupId="os" items={['Windows', 'macOS / Linux']} persist>
  <Tab value="Windows">

Install with [Scoop](https://scoop.sh), in PowerShell:

```powershell
scoop bucket add privasys https://github.com/Privasys/scoop-bucket
scoop install privasys
```

No Scoop yet? Install it first (no administrator rights needed). This runs Scoop's own installer from get.scoop.sh, which you can [read before you run it](https://github.com/ScoopInstaller/Install/blob/master/install.ps1):

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression
```

You can also download `privasys_<version>_windows_amd64.zip` (or `_arm64`) from the [latest release](https://github.com/Privasys/cli/releases/latest), check it against `checksums.txt`, and put `privasys.exe` on your `PATH`.

  </Tab>
  <Tab value="macOS / Linux">

The install script, which you can [read before you run it](https://github.com/Privasys/cli/blob/main/install.sh):

```sh
curl -fsSL https://raw.githubusercontent.com/Privasys/cli/main/install.sh | sh
```

Or with Homebrew:

```sh
brew install Privasys/tap/privasys
```

Debian and RPM packages (`.deb` / `.rpm`) are attached to each [release](https://github.com/Privasys/cli/releases). Inside WSL, use the install script as on Linux.

  </Tab>
</Tabs>

Raw archives for every OS and architecture, with their `checksums.txt`, are attached to each [GitHub release](https://github.com/Privasys/cli/releases).

<Callout type="info">
`go install` is not supported. The CLI performs client-side RA-TLS, which links the RA-TLS client library and is built with the [Privasys Go fork](https://github.com/Privasys/go). Use the released binaries or one of the package managers above.
</Callout>

## Verify

```sh
privasys version
```

<Callout type="warn">
If you install into a shell whose applications are already running (an editor, an agent, a terminal multiplexer), restart them so they pick up the updated PATH. A running app keeps the PATH it started with.
</Callout>

## Update

The CLI updates itself:

```sh
privasys update            # update to the latest release
privasys update --check    # only report whether a newer release exists
```

Package-manager installs are delegated to the package manager (`scoop update privasys`, `brew upgrade privasys`); script or manual installs are replaced in place after the binary's checksum is verified against the release's `checksums.txt`. With Scoop, run `scoop update` first so Scoop fetches the bucket and sees the new release, then `scoop update privasys`.
